## 始める前に

既存の Issue と Pull Request を確認してください。大きな機能は、実装前に問題と提案する動作を Issue で相談してください。小さな修正は直接 PR を送れます。英語、ポルトガル語、日本語で報告・議論できます。

Steam の認証情報、個人のファイルパス、非公開ログ、ダウンロードした MOD、第三者の著作物を投稿しないでください。MOD 作者と Steam のアクセス制限を尊重してください。

## 開発手順

1. リポジトリを Fork し、`main` からブランチを作成します。
2. Rust 1.96.1+、MSVC、C++ Build Tools、Windows SDK を用意します。
3. 変更を一つの目的に絞ります。GPUI のネイティブ UI、コンパクトなボタン、丸い透明な輪郭、押下アニメーションを維持してください。
4. 動作変更には回帰テストを追加します。UI 変更には実際の Windows の画像か動画と、画面の拡大率を添付してください。
5. 次を実行します。

```powershell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo build --release --locked
```

6. 問題、変更後の動作、検証方法、残る制限を説明する PR を作成し、関連 Issue をリンクします。

表示文字列は `src/i18n.rs` に追加します。英語・ポルトガル語・日本語の翻訳を含めるか、PR で翻訳の支援を依頼してください。動作を変更した場合はすべての README を更新します。

## 品質と安全性

モジュールの役割を明確に保ちます。厳密なリンク検証、匿名アクセス、キャンセル、子プロセスの終了、上書きしないコピーを維持してください。テレメトリーやログイン機能は事前に設計を相談します。依存関係変更時は Cargo.lock を含め、ライセンスを確認し、第三者ライセンス通知を再生成してください。ユーザーが入力したシェルコマンドを実行しないでください。

依存関係の変更前に cargo-audit の `cargo audit` を実行します。既存の保守アドバイザリーは [DEPENDENCIES.md](DEPENDENCIES.md) に記載されています。新しい警告は解決または評価が必要です。パッケージ作成は `scripts/package.ps1` と Inno Setup 6 を使用します。
