# Application artwork

Original AI-generated artwork created with the built-in OpenAI image generation tool for this project. Used as Windows executable, taskbar, shortcut and installer artwork. This illustration represents the visual concept; it is not an application screenshot.

Prompt: a premium minimal 3D icon inspired by a matte black portable audio recorder turned into a download appliance. Upright rounded black device, recessed smoky LCD with a warm gray download arrow and tray, large physical circular control, muted red indicator, fine beveled edges and realistic studio highlights. Dark graphite palette, generous transparent margins, no text, logos or surrounding frame.

The PNG is the original transparent output. The ICO contains sizes from 16 to 256 pixels for Windows packaging. Project artwork is distributed with the project under the MIT license; third-party trademarks are not part of it.

## Taskbar revision (1.0.1)

Edited with the built-in image generation tool using the original artwork as the reference. Prompt: retain the matte graphite download device, warm gray arrow, recessed LCD, circular control and red indicator. Make the body nearly square and fill almost the whole canvas; remove the protruding microphones and simplify tiny details for 16/32-pixel legibility. Keep genuine transparent antialiased edges and no surrounding tile or text.

The revised visible silhouette covers approximately 92% of the square canvas width, giving the Windows icon much more presence. The ICO still contains 16, 24, 32, 48, 64, 128 and 256-pixel images.
