# Workshop Device 1.0.1

Larger taskbar icon: the device now fills approximately 92% of the icon width, with a compact body and a clearer download arrow. This release also gives the automated publishing job explicit permission to retrieve its build artifacts.

- Compact vertical interface with rounded transparent corners, engraved window controls and physical button animation.
- Paste a mod link, choose a folder and download using the official SteamCMD.
- English, Portuguese and Japanese; the initial language follows Windows.
- Settings inside the display; optional folder opening after completion.
- In-app errors, cancellation and a new folder for each completed download.
- Original application icon, per-user installer and portable package.
- Public source code and multilingual contribution guides. Contributions are welcome.

## Downloads

- **Workshop-Device-Setup-1.0.1.exe** — recommended installer; no administrator needed.
- **Workshop-Device-1.0.1-windows-x64.zip** — portable application with documentation and license notices.
- **Workshop-Device.exe** — standalone executable; also available inside both packages.
- **SHA256SUMS.txt** — release file checksums.
- **LICENSE** and **THIRD-PARTY-NOTICES.html** — license notices; keep them with the standalone executable.

Windows 10/11 x64. Internet and a compatible graphics driver are required. This release is unsigned.

Only individual Project Zomboid items that permit anonymous SteamCMD access are supported. Collections and login-required downloads are unsupported. The app saves files; it does not install or activate mods in the game.
